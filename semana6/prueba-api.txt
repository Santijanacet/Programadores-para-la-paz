Cuando se envía una petición POST a http://localhost:3000/registro con el JSON:

{
  "nombre": "Santiago",
  "mensaje": "Hola comunidad"
}

El servidor recibe los datos mediante req.body (procesados por express.json()) y devuelve la siguiente respuesta en formato JSON:

{
  "estado": "Datos recibidos",
  "nombre": "Santiago",
  "mensaje": "Hola comunidad"
}
